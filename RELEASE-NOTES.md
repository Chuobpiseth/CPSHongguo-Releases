# Release notes

## 0.1.0 — 30 September 2026

- Introduced the CPS Hongguo Downloader Electron and React desktop client.
- Added branded application/taskbar icons and a logo-based startup screen.
- Added poster browsing, search, queue controls, and local library management.
- Added scheduled downloads, bandwidth profiles, duplicate detection, download
  integrity status, and native Windows notifications.
- Added animated 0–100% download progress.
- Added Legacy Light/Dark and Liquid Glass Light/Dark themes.
- Kept license activation disabled during initial UAT.
