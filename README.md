# CPSHongguo-Releases

Public update channel for **CPS Hongguo Downloader**, developed by
**Chuob Piseth**.

This repository intentionally contains no application source code. Installers,
update metadata, checksums, and release notes are published through GitHub
Releases.

## Product

- Application: CPS Hongguo Downloader
- Developer: Chuob Piseth
- Contact: Chuob.piseth.official@gmail.com
- Initial version: 0.1.0
- First release date: 30 September 2026

## Downloads

Use the repository's **Releases** page to obtain official builds. Do not run
files supplied through unofficial mirrors.

## Update assets

Each published GitHub Release used by the in-app updater must contain:

- `CPS-Hongguo-Downloader-update-<version>.zip`
- `CPS-Hongguo-Downloader-update-<version>.zip.sha256`
- Release notes

Use a matching tag such as `v0.1.0`. The ZIP must contain the complete contents
of Electron Builder's `win-unpacked` directory at its root. Source code is
maintained separately in a private repository.
